# Security Policy

## Supported versions

This repository is pre-release. Security corrections are applied only to the current main branch until a supported release line is declared.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, or private project data. The repository owner is `@JerrettDavis`; a private reporting address is not yet established and must be selected before external distribution.

Never include production credentials or private modeled content in a report, fixture, log, or artifact.
